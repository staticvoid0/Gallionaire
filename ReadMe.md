👑 ⚔️ Gallionaire v2.6.6 ⚔ 👑

[Download Gallionaire](https://github.com/staticvoid0/Gallionaire/releases/download/2.6.3/Gallionaire.zip)

💡 Overview

Tracks and displays key Sortie data and progression items.

Tracks Total Gallimaufry, record galli gain, and current run galli.

Auto-opens closed doors; Now no longer interacts with doors that are already open.

Displays Gallionaire Logo in Green when all 6 players are within 15 yalms, giving the user a boss-pull indicator.

Introducing the Absorb-TP readout. Gallionaire now tracks and displays all absorb-TP spells cast specifically on Aminon.

Added Aminon TP tracking to the TP readout as well as notifications when something is not as it should be including someone engaged (excluding Monk mainjob) Absorbs failing to land which indicates Frazzle III or Dark Threnody II not being on, the tank taking damage and more.

Tracks and displays Rusplix Plate and Shiny Plate timers.

Tracks Sortie NPCs.

No known issues 🙂

⚙️ Installation

Extract to your Windower addons folder.
Folder name: Gallionaire

Windower4/addons/Gallionaire/Gallionaire.lua


Load the addon:

lua load Gallionaire


🧭 Commands

| Command                          | Alias     | Description                                                                                                     |
| -------------------------------- | --------- | --------------------------------------------------------------------------------------------------------------- |
| `//ga togglesound`               | `//ga ts` | Toggle sound effects on/off. *(On by default)*                                                                  |
| `//ga reset`                     | —         | Reset your earned Gallimaufry counter.                                                                          |
| `//ga reload`                    | `//ga r`  | Reload the addon.                                                                                               |
| `//ga show`                      | —         | Make the display visible.                                                                                       |
| `//ga hide`                      | —         | Hide the display.                                                                                               |
| `//ga tp`                        | —         | Toggle visibility of the Aminon Absorb-TP readout.                                                              |
| `//ga tpreset`                   | —         | Resets the data in the Absorb-TP readout.                                                                       | 
| `//ga setruspix`                 | —         | Manually set Ruspix Plate timer in seconds (time given upon entering Sortie or talking to Ruspix in Leafallia). |
| `//ga pickup`                    | —         | Manually start your Shiny Plate timer. *(Debugging feature, left for utility.)*                                 |
| `//ga resettimer`                | —         | Manually clear your Shiny Plate timer. *(Debugging feature, left for utility.)*                                 |
| `//ga auto on` / `//ga auto off` | —         | Toggle automatic door opening.                                                                                  |
| `//ga help`                      | —         | Display this list of commands in the in-game log.                                                               |
